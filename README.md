# Scraper_date
scraper_date - это программа осуществляющая сбор данных с сайта в сети интернет.


# Основной функционал:
1. Сбор данных с сайта в сети интернет.
2. Обработка данных и построение графиков.


# Работа scraper_date.

   Файл scraper_date запускается из командной строки.
1. После запуска scraper_date он автоматически начинает сбор данных с указанного сайта.
2. В scraper_date находятся следующие основные функции: scrape_item_prices отвечающая за сбор данных с сайта,
внутри scrape_item_prices находится функция date_csv отвечающая за создание архивного файла и запись в него данных;
interval_scraper отвечающаая за периоды в которые scrape_item_prices не выполняет запросы данных с сайта так как
обновление данных на сайте происходит не круглосуточно.
3. Полученные данные записываются в файл date.csv.
4. Для обработки данных и построения графиков необходимо запустить файл grafhics.py.
5. Графики создаваемые grafhics.py сохраняются отдельными файлами в корневой директории.


   У scraper_date существует графическая интерфейс gui_scraper основанный на библиотеке Flet.
Файл gui_scraper запускается из командной строки.
1. После запуска gui_scraper для начала сбора данных необходимо нажать на кнопку "Запустить сбор данных".
2. Для остановки сбора  данных необходимо необходимо нажать на кнопку "Остановить сбор данных".
3. Gui_scraper отображает последние данные собранные scraper.
4. Gui_scraper отображает сведенея о работе собственного планировщика настроенного на период
с 7-15 до 23-45, кроме субботы и воскресенья, а также  выводит информацию о возможности запросов данных
в текущий момент.

# Обработка данных и построение графиков.
1. Для построения графиков необходимо запустить grafhics.py.
2. Для построения графиков используются данные файла date.csv 
3. Созданные графики сохраняются в отдельные файлы в корневой директории проекта. 
4. Имена файлов с графиками: week_minute.png, week_hour.png,day_minute.png,distribution.png.

# Структура проекта.

В проект входят следующие файлы:
1. scraper_date.py - выполняет сбор  данных с сайта, выполняет обработку данных и их запись в архивный файл.
2. date.csv - в файле находятся архив собранных данных.
3. grafhics.py - выполняет обработку архивных данных и осуществляет построение графиков.
4. gui_scraper.py- графический интерфейс для запуска и остановки работы scraper. 
5. gitignor. 
6. README.md 
7. requirements.txt


# Дополнительные условия.

1. Scraper_date настроен на выполнение запросов с конкретного сайта в период с 7-15
до 23-45, кроме субботы и воскресенья, чтобы исключить выполнение запросов в период
когда на сайте отсутствует обновление данных. В случае запуска scraper_date в период 
не попадающий в указанные интервалы программа сообщит о невозможности выполнить 
запрос и укажет до какого времени будет находиться в режиме ожидания.
2. Для работы необходим установенный браузер Microsoft Edge версии 140.0.3485.81.
