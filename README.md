# Scraper_date
scraper_date - это программа осуществляющая сбор данных с сайта в сети интернет.

# Основной функционал:
1. Сбор данных с сайта в сети интернет.
2. Обработка данных и построение графиков.


# Работа scraper_date.

1. После запуска scraper_date он автоматически начинает сбор данных с указанного сайта.
2. В scraper_date находятся следующие основные функции: scrape_item_prices отвечающая за сбор данных с сайта,
внутри scrape_item_prices находится функция date_csv отвечающая за создание архивного файла и запись в него данных;
interval_scraper отвечающаая за периоды в которые scrape_item_prices выполняет запросы данных с сайта так как
обновление данных на сайте происходит не круглосуточно.
3. Полученные данные записываются в файл date.csv.
4. Для обработки данных и построения графиков необходимо запустить файл grafhics.py.
5. Графики создаваемые grafhics.py сохраняются отдельными файлами.

# Структура проекта.

В проект входят следующие файлы:
1. skraper_date.py - выполняет сбор  данных с сайта, выполняет обработку данных и их запись в архивный файл.
2. date.csv - в файле находятся архив собранных данных.
3. grafhics.py - выполняет обработку архивных данных и осуществляет построение графиков.
4. gitignor.
5. README.md
6. requirements.txt
